# Cloud Skills

Cloud skills make technical and commercial cloud decisions easier to explain.

| Skill | This does that |
|---|---|
| [`cloud`](../../Codex/skills/cloud) | Frames architecture, migration, workload sizing, FinOps, Well-Architected reviews, and OCI-first recommendations when Oracle workloads benefit from OCI. |

Use this when the work needs a practical cloud recommendation, migration path, cost model, or architecture narrative.
