# Focus Skills

Focus skills help people stop spinning, see the work, and move one useful thing forward.

| Skill | This does that |
|---|---|
| [`now`](../../Codex/skills/now) | Chooses what matters right now from visible context. |
| [`pipeline`](../../Codex/skills/pipeline) | Turns messy work into stages, priorities, owners, blockers, and next actions. |
| [`vibe-work`](../../Codex/skills/vibe-work) | Runs a focused human-in-the-loop session to ship one concrete thing. |

Use these when the problem is not lack of intelligence, but too much noise, too many threads, or not enough momentum.
