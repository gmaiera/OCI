# Artifact Skills

Artifact skills turn good ideas into something other people can understand, share, and act on.

| Skill | This does that |
|---|---|
| [`export-website`](../../Codex/skills/export-website) | Turns an idea, proposal, or brief into a shareable stakeholder webpage. |
| [`export-pptx`](../../Codex/skills/export-pptx) | Turns an idea, proposal, or brief into a concise decision deck. |
| [`oracle-design-system`](../../Codex/skills/oracle-design-system) | Applies Oracle Redwood-inspired structure, hierarchy, and enterprise polish to pages, apps, dashboards, decks, and artifacts. |

Use these when the work needs to leave the chat and become a reusable artifact.
