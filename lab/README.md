# Lab

The lab is where OCI skills are designed, tested, promoted, and prepared for public sharing.

| Area | This does that |
|---|---|
| [`Codex/skills-lab`](../Codex/skills-lab) | Holds sandbox, candidate, production, eval, and release-script workflows. |
| [`Codex/skills`](../Codex/skills) | Holds the plugin-compatible public skill packages. |
| [`skills`](../skills) | Provides visitor-friendly navigation by outcome. |

Use the lab when you are creating or improving a skill. Use the public `skills/` indexes when you are deciding which skill to use.
