# Publication Checklist

Before pushing public content:

- No live `.env` values, API keys, tokens, private keys, cookies, or OAuth material.
- No Oracle confidential context, internal URLs, customer data, or work product.
- No Mesttra private strategy, customer data, WhatsApp logs, or raw lead exports.
- No local machine paths, internal IPs/ports, runtime logs, or Codex session state.
- Generic skills and docs are sanitized for public reuse.
- `./codex-config/scripts/public-content-scan` has been reviewed.
